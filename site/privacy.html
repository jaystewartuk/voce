voce

What goes where

voce has no accounts, no analytics and no cookies, and there is no voce server holding anything of yours. This page lists every place your text or your data can go, so you can check it.

The terminal app

  • voce makes no network calls of its own. There is no telemetry.
  • Your place and settings are one JSON file in ~/.local/state/voce. Audio is cached in ~/.cache/voce, and you can delete it at any time.
  • Every voice runs on your computer: Kokoro, whose model is downloaded once from Hugging Face, and the Mac's own voices. What you read is never sent anywhere to be spoken.
  • With voce --sync, your places go to a private GitHub repository of yours, through your own git.

The web app, without signing in

  • What you open, and your place in it, is kept in this browser and nowhere else. Clearing the site's data in your browser removes it.
  • A file you open is read in the page. It is not uploaded anywhere.
  • A web page you ask for is fetched by your browser where the site allows that. Most sites don't let one page read another, so then voce's relay fetches it instead: a small function on Cloudflare Workers that fetches the address, hands the page back and keeps nothing. It writes no log. The site sees the relay, not you. The relay's code is in the repository.

The web app, signed in with GitHub

  • Signing in uses the voce GitHub App. It can read and write only the repositories you install it on, and only their files. You choose which.
  • GitHub sends the page a sign-in code, and the relay swaps it for a token, because that step needs a secret a web page can't hold. The token comes back to this browser and is kept there. From then on, the page talks to GitHub directly.
  • Your library and your places go only between this browser and your repository. They never pass through the relay.
  • "Disconnect this device" in settings forgets the token. To cut off every device at once, remove voce at github.com/settings/installations.

The voices in the web app

  • Kokoro runs in the page, on your device. Its model is downloaded once from Hugging Face and kept by the browser. Nothing you read is sent anywhere.
  • "This device's voice" is whatever your browser or system provides. Most run on the device, but some are online voices: in Chrome, the ones named "Google …", and in Edge, the ones marked "Online", send the text to Google or Microsoft to be spoken. Choose Kokoro or an offline voice if that matters to you.

Who else sees a request

  • GitHub Pages serves this site, and GitHub's API holds a signed-in library.
  • jsDelivr serves the code the web app loads on first use: Python for the browser (Pyodide), the Kokoro runtime, and Readability and Turndown for web pages. Hugging Face serves the Kokoro model.
  • Cloudflare runs the relay.

Each of them sees your IP address when your browser asks it for something, as any website does. None of them gets your library or your place from voce.

Questions or something that doesn't match? Open an issue. voce is open source, so all of the above can be checked in the code.
