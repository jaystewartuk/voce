voce

Your library, on this device

voce keeps your places and prepared documents in a private git repository of yours. On the Mac, voce --sync OWNER/REPO made it. Connect this device to the same one.

Sign in, and GitHub lets this page read and write that one repository. Nothing is sent anywhere but GitHub; the token stays in this browser.

Or paste a token

Make one at github.com/settings/personal-access-tokens/new. It stays in this browser and goes only to api.github.com.
