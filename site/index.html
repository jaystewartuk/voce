How micrograd learns

Every number is a Value that remembers the values it was made from, so the gradient can flow back through them. Multiplying two of them sets up the chain rule for that one step:

pythondef __mul__(self, other):
    other = other if isinstance(other, Value) else Value(other)
    out = Value(self.data * other.data, (self, other), '*')

    def _backward():
        self.grad += other.data * out.grad
        other.grad += self.data * out.grad
    out._backward = _backward
    return out

Code, read aloud

Code, read the way a pairing partner says it.

Every reader that speaks code gets it wrong in one of two ways. Screen readers spell out the symbols: "dollar, totals, left bracket, dollar, channel". Text-to-speech apps read code as prose, and Str::slug comes out as "stress log". voce says what the person next to you would say, one line at a time, and the line lights up as it is read.

Real names, so you learn them

Operators are called what their own manual calls them: PHP's "identical", JavaScript's "strictly equal", Ruby's "spaceship", Kotlin's "elvis", Go's "bit clear", Rust's "turbofish", C#'s "null conditional". After a few sessions you say them without thinking, which is what a pair-programming interview or a code review asks of you.

Names as words

array_values is "array values", strlen is "string length", usort is "U sort", isset is "is set". A variable's dollar sign, the brackets and the semicolon are silent. A string is read by its contents, and a trailing comment as prose.

Checked against real code

The rules started with PHP, read right through laravel/framework and checked by ear against the real voice. Every other language was then read through well-known projects in that language (Django, express, Guava, ripgrep, Rails and others) and its operator names checked against its manual by a reviewer who had not seen the rules. A pipe in shell is "pipe", Python's -> is "returns", and each language has tests with the exact words. Hear it on a reservation sync in Laravel, or prefer the prose alone with --skip-code.

How it compares

Other readers speak code. None of them say it.

voce is not a screen reader and doesn't try to be one. It is for listening to things worth taking in: an agent's explanation, a pull request walkthrough, study notes on a language.

What it does

Reads what a person would read.

Markdown is written for the eye. voce shows it the way it should look and reads only the prose, so you can listen with your eyes closed or follow every word.

Follows along

The sentence being read sits on a pale band, the word being spoken on a darker one, timed from the audio itself.

Reads code like a pairing partner

Highlighted in every language Pygments knows, and read line by line with the real names: "is identical to", "double arrow", "null coalescing", "spaceship".

Tables that line up

Columns are aligned on screen and read one row at a time, cell by cell.

Keeps your place

Quit at any point and carry on from the same sentence, even after the file has been edited.

Free to listen again

Every sentence is fetched once and cached, so going back or listening again costs nothing and works offline.

Take it with you

--export stitches files into one MP3, with the same voice and pauses, for a walk or a drive.

Playlists and quizzes

Point it at a folder's README and listen through in order. Quizzes pause for your answer.

Click to jump

Click any sentence to hear it, or use the arrows to move by sentence, paragraph or section.

Gapless and in time

A tiny native player keeps sentences flowing, pauses mid-word and changes speed without changing pitch.

Install

Ready in a minute.

You need macOS or Linux, and Python 3.10 to 3.14 for the Kokoro voice. On a Mac, the Xcode command line tools give you the gapless player. On Linux, mpv plays the audio. ffmpeg is only needed for MP3 export.

# with uv
❯ uv tool install --python 3.13 voce
# or with pipx
❯ pipx install --python python3.13 voce
❯ voce README.md # any Markdown file
❯ voce -r # Claude Code's latest reply
❯ voce -c # the clipboard
❯ voce notes.md --export notes.mp3

Full documentation is in the README.

Privacy

Your notes stay yours.

No telemetry

voce makes no network calls of its own. There is nothing to opt out of.

Nothing leaves your computer

The voices run locally, so what you read is never sent to a speech service.

Plain files

Your place and settings live in one JSON file, and the audio cache is safe to delete at any time.

The web app works without an account, and keeps what you read in your browser. What goes where lists everything voce keeps and sends, and to whom.
