# Filling your library

There are four ways to add something to listen to.

1. Paste a web page's address into the box under your library. voce takes the article out of the page and keeps
   it here.
2. Open a Markdown, text or HTML file from your device.
3. On Android, share a page or some text to voce from any app.
4. Write your own playlist: put Markdown files in this repository and list them in the README, under "Listen in
   this order".

The fourth is where a coding agent helps. Ask Claude Code, Codex or Cursor, in a copy of this repository, something
like "write me a playlist that teaches Rust's ownership rules, ten minutes a part". The notes for it are in
AGENTS.md. It writes the files and the playlist; push them, and they appear on every device.

You can also add a playlist from any other repository you can reach, in settings.
