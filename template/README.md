# My voce library

What I listen to with [voce](https://jaystewartuk.github.io/voce/), and my place in each. voce reads this README's
playlist on every device; what I add in the web app goes in `items/` and `texts/`, and my places in `places/`.

To add to the playlist, put a Markdown file in this repository and list it below. A coding agent can do it for
you: see [AGENTS.md](AGENTS.md).
